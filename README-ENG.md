## 📘 Project Description

This repository contains a digital version of the Galaxy Trucker board game, developed entirely in Java.
The graphical interface is built using Java **Swing**.

---

## 🕹️ Implemented Game Modes

The game is complete and supports the **four main modes** of the original game:

1. **Trial Level**
2. **Level One**
3. **Level Two**
4. **Level Three**

The rules are implemented to reflect the actual board game rules as faithfully as possible.

---

## ⚠️ Simplifications compared to the original game

Due to time constraints, the following **simplifications** compared to the original game have been introduced:

- The game is structured with a **turn-based system**, as it is playable only **locally** (not online).
- The assembly phase is therefore **adapted** to a turn-based system.
- The **Trasvolata Intergalattica** mode is not included.
- The **Zona di Guerra** card is not included.
- The starting order is **fixed** based on the ship completion order even for non-test flights, rather than being selectable.
- Total available goods are **not limited** as in the real game.
